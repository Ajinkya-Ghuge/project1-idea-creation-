This study was part of an internship at Feynn Labs©, under the guidance of Mr. Sanjay Basumatary (Internship Mentor).
I worked on a project prototype idea titled “Datasphere: ML-Driven Expiry Date Prediction for Waste Reduction”, focusing on developing a solution to reduce spoilage-related losses in the Indian market — especially in food, dairy, and pharmaceutical sectors — using machine learning.
🔍 Problem Statement:
India faces an annual loss of ₹1.9 trillion due to expired goods, worsened by poor storage conditions and fixed expiry date systems. Small kirana stores and pharmacies are especially vulnerable.
⚙️ Machine Learning Techniques Used:
We implemented the following algorithms to create and evaluate the prediction system:
Random Forest Regression for expiry prediction
Exploratory Data Analysis (EDA) for pattern recognition
Model Evaluation Metrics such as R² Score and MAE to measure accuracy
🧪 Prototype Overview:
Built a Flask-based web app with machine learning integration
Trained on real-world datasets (Kaggle & simulated retail data)
Database: SQLite
Deployment-ready structure with scalable backend logic
📈 Results & Market Scope:
Target Segment: Kirana stores & pharmacies in India (13M+ potential clients)
Predicted Expiry helps reduce inventory waste and optimize shelf management
MVP Cost Range: ₹400–700 subscription tier based on per capita income
Projected Early Market Size: ₹100M revenue potential
✅ Conclusion:
This project focused on using AI to solve real-world business problems, especially in sectors where expiry date mismanagement leads to major financial loss. The prototype uses Random Forest for accurate predictions and is designed to be scalable, cost-effective, and impactful across India's massive retail base.# project1-idea-creation-
